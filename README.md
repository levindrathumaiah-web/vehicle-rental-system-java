# Vehicle Rental System

A Java console application developed using Object-Oriented Programming principles.

## Features

- Vehicle rental management
- Car and Motorcycle subclasses
- Rental cost calculation
- Method overriding
- Polymorphism
- ArrayList collections

## Technologies

- Java
- IntelliJ IDEA

## OOP Concepts Demonstrated

- Inheritance
- Encapsulation
- Polymorphism
- Constructors
- Method Overriding
- Getters and Setters
